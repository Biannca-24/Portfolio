# 💜 Portfólio — Bianca Sabino

Meu portfólio pessoal, desenvolvido do zero para reunir os projetos que 
venho construindo nas trilhas da Rocketseat e na faculdade.



## 💡 Sobre o projeto

Site com apresentação pessoal, projetos em destaque, formação acadêmica 
e stack de tecnologias, com suporte a tema claro/escuro (com preferência 
salva no navegador).

## ✨ Funcionalidades

- Alternância de tema claro/escuro com persistência via `localStorage`
- Fundo em mesh gradient, gerado em CSS puro (sem imagens)
- Seção de projetos em destaque com print e links de repositório/deploy
- Seção de formação acadêmica e cursos em andamento
- Ícones de tecnologias com fallback automático (caso o CDN falhe)
- Totalmente responsivo — mobile, tablet e desktop

## 🛠️ Tecnologias

- HTML5
- CSS3 (custom properties, grid, flexbox)
- JavaScript (vanilla, sem frameworks)
